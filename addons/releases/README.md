# Az Design installer packages

Download **AzDesign-0.1.0.zip**, extract it, then run **Install_AzDesign.FCMacro**
from FreeCAD's Macro menu. See `AzDesign/README.md` inside the package for details.

These small standalone packages are included so users do not need to download
or build the complete FreeCAD fork. Source is in `addons/AzDesign`; rebuild with
`python3 tools/package_azdesign.py --output addons/releases/AzDesign-0.1.0.zip`.

Version 0.1.0 was tested in FreeCAD 1.0.0 on Linux with Qt 5 / PySide2. Other
operating systems and FreeCAD versions have not been verified.
